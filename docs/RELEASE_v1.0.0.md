# Agy Powertools (Codex 定制版) v1.0.0

本版采用独立版本号体系首发，完整集成上游 [`WhiteBr1ck/agy-powertools`](https://github.com/WhiteBr1ck/agy-powertools) **`v2.15.5`**（MIT 协议）全部能力，主打**「高度还原 Codex 桌面端交互与视觉手感」**，更新源已指向本仓库。

## 核心体验优化（按类别一览）

### 1. 对话排版与视觉配色
- 全面对齐 Codex 深浅双色画布、`48rem` 齐边对话列宽、`1.625` 舒适行高与段距。
- 采用无边框圆润提问气泡、柔和半透明行内代码方牌、悬停虚线蓝色文件链接与极简无框横线表格。
- 零配置内置可用预设，本机装有 Codex 时自动静默匹配其外观与字号，且仍支持开启自定义气泡着色。

### 2. 流式工作进度与精简排版输出
- 打通「日常工作」与「软件开发」两种布局的实时进度展示，取消狭窄的 `320px` 限高滚动盒，阶段汇报亮色直出、连续工具调用压缩为单行灰字摘要。
- 工作未完成前不再提前误显复制与点赞栏；整轮结束后自动折叠为干净的单行「用时 X分X秒」，无操作不留空折叠箭头，人工审批步骤保持内联不收起。
- 开启「Codex 风格体验」自动升级接管原「阶段汇报」动态请求提示词（绝不改动本机 `~/.gemini/AGENTS.md`），内置结论先行、默认十行内精简回答、克制反引号、句尾链接与工具摘要汉化规范，关闭开关即回退原版。

### 3. 划词与文件/图片横向右键胶囊
- 左键划词、选中文本右键、以及对话里的文件、目录、产物卡片、图片与右侧文件树右键，全部统一为 Codex 同款横向双按钮胶囊 **「添加到对话 | 在侧边聊天中提问」**，直接取代冗余竖向菜单并支持拉起侧边提问。

### 4. 高清原图上传与 122×122 大图预览
- 输入框贴图自动撑高展示 `122×122` 圆角高清预览卡（侧边栏为 `88×88`）与悬停圆形移除按钮。
- 突破默认 1 MiB 压缩限制，支持 3 MiB 内原图无损直传与超限保尺寸自适应收敛，并将极糊的 10 KiB 缩略图提升至 160 KiB Retina 清晰度。

### 5. 极简双开关与全量汉化补充
- 在设置首栏独立收拢为仅有的两个开关：**「Codex 风格体验」** 与 **「高清原图上传（≤ 3 MiB）」**，一键启停、完整可逆且不混入原版分栏。
- 补全 Antigravity 2.35+ 子智能体、后台任务、定时器、权限审批与右键菜单缺字图标等遗漏。
- 完整保留上游 `v2.15.5` 的统计看板、上下文与速度监测、会话分支、原位编辑、多账号切换、免 TUN 代理、macOS 冷启动自动重启、SSH 与 WSL2 全部能力。

## 快速安装

### 方式一：发给 Agent 自动安装（推荐）

> 请帮我安装 Agy Powertools (Codex 定制版)：https://github.com/xiejunjie168-bot/agy-powertools 。先阅读 README 和 docs/INSTALL_AGENT.md，使用项目提供的统一安装器，优先使用已有 Node.js 或 Antigravity 自带运行环境。保留其他插件、账户设置和聊天记录，不要强制退出当前客户端。安装后核对版本并告诉我结果；需要重启时最后提醒我。

### 方式二：手动下载安装

下载本页附件中的 `agy-powertools-v1.0.0.zip` 解压，在解压目录执行：

- **macOS / Linux / WSL2**：`sh ./install.sh`
- **Windows (PowerShell)**：`powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1`

安装完成后请完全退出并重启 Antigravity（macOS 请按 `Cmd + Q`）即可生效。
