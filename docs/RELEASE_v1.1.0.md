# Agy Powertools (Codex 定制版) v1.1.0

本版完整集成上游 [`WhiteBr1ck/agy-powertools`](https://github.com/WhiteBr1ck/agy-powertools) **`v2.16.0` 至 `v2.16.3`**（MIT 协议）全部能力，并在对话交互、流式进度、快捷操控与左侧栏视觉上进一步对齐 Codex 桌面端体验；应用内检查更新与自动提醒均已对接本仓库独立版本线。

## 本版新增亮点

### 1. Codex 桌面端体验深化
- **左侧栏 Codex 换肤（保留原生结构）**：在保留置顶会话、项目分组与工作区结构的前提下，统一对齐 #202020 侧栏画布、无框新建会话按钮、无阴影 #323232 激活胶囊，以及 14px 全栏字号、#8F8F8F 分区灰字和 #D2D2D2 柔和主色。
- **输入框顶部注释胶囊与已发引用美颜**：划词或选中文件引用改为挂在输入框上方的 Codex 同款紧凑注释胶囊（支持预览与逐条移除，发送时自动拼回原生引用），用户消息气泡里的引用标签也统一显示为圆角胶囊。
- **模型按钮右键快切思考深度**：在底部模型选择器上直接点击右键，即可按当前模型组列出全部支持档位及额度状态一键切换，单档位模型自动保持原生无干扰。
- **正文细节与钩子行对齐**：完成工作步骤在最终正文开始输出时自动折拢并修复流式汇报阶段误折闪烁；同步对齐代码块卡片、底部操作栏默认淡隐悬停显示、思考微光节奏，以及钩子运行面板的嵌套折叠行对齐与标题汉化。

### 2. 完整集成上游 v2.16.0 - v2.16.3
- **自动检查更新、轻量提醒与可选空闲热更新（#45）**：在「关于」栏新增「启动时自动检查更新」（每 12 小时或在客户端升级后自动检查本仓库新版）与「空闲时自动热更新」（默认关闭，仅同大版本且会话空闲时静默安装），发现新版时显示侧栏「新版」徽标、顶栏状态点与右下角提醒浮卡。
- **长对话防卡顿与原位编辑修复（#51、#58）**：历史完成轮次改用 O(1) 值签名缓存并引入滚动防抖与 6 秒空闲轮询退避；修复重启后首个历史会话原位编辑按回车或点击发送未直接回退重发的问题。
- **多账号、代理与 SSH 稳定性加固（#53、#56、#57、#59）**：Windows 切换为零 AMSI 临时 `.lnk` 代理拉起；添加账号期间展示可复制 Google OAuth 登录链接并支持取消；多账号切换同步登录条款确认状态；SSH 远端窗口自动隔离本地多账号列表并保留原生设置入口，修复 SSH 概览默认筛选为 0（#49）。
- **日常实用增强（#48、#50、#55、#60）**：支持概览 3D 思考球 `ThinkingOrb`、标准价与 API 优惠口径切换、仅复制最终回答、`/compact` 压缩后即时上下文估值、聊天内联图片右键操作，以及补全 Antigravity 2.35.1 Skills、Customizations 与 MCP 界面汉化（同时排除代码块与 Diff 视图防误翻）。

## 快速安装

### 方式一：发给 Agent 自动安装（推荐）

> 请帮我安装或升级 Agy Powertools (Codex 定制版)：https://github.com/xiejunjie168-bot/agy-powertools 。先阅读 README 和 docs/INSTALL_AGENT.md，使用项目提供的统一安装器，优先使用已有 Node.js 或 Antigravity 自带运行环境。保留其他插件、账户设置和聊天记录，不要强制退出当前客户端。安装后核对版本并告诉我结果；需要重启时最后提醒我。

### 方式二：手动下载安装

下载本页附件中的 `agy-powertools-v1.1.0.zip` 解压，在解压目录执行：

- **macOS / Linux / WSL2**：`sh ./install.sh`
- **Windows (PowerShell)**：`powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1`

安装完成后请完全退出并重启 Antigravity（macOS 请按 `Cmd + Q`）即可生效；已安装 `v1.0.0` 的用户也可在 **Powertools -> 设置 -> 关于** 中一键检查并更新。
